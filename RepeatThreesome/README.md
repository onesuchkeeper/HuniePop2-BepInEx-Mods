# Repeat Threesome
Allows repeatable threesomes and more in the game [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features
* Repeatable threesomes after reaching lovers status
* A nude outfit for every character
* Toggleable nudity during bonus rounds
* Toggleable location requirement for threesomes

## Installation
To install, first download the Hp2BaseMod, then download, unzip and place the RepeatThreesome folder in BepInEx/plugins
