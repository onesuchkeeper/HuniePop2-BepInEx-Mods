# ExpandedWardrobe

Adds new outfits and hairstyles to [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features

* At least 1 new style for every character in the base game!
* 33 new styles total!

To configure, you may edit the config file `BepInEx/config/OSK.BepInEx.ExpandedWardrobe.cfg`. This can be done in notepad or any other text editor. There you may turn disable any particular character's styles.

## Dependencies
* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](https://onesuchkeeper.itch.io/hp2basemod)
