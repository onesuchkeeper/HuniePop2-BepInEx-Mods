# ExpandedWardrobe

Adds new outfits and hairstyles to [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features

* At least 1 new style for every character in the base game!
* 33 new styles total!

## Dependencies & Installation

### Dependencies
* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](../Hp2BaseMod/README.md)

### Installation
* Install [**Hp2BaseMod**](../Hp2BaseMod/README.md)
* [**Download**](https://scallycapfan.itch.io/expanded-wardrobe), unzip and place the ExpandedWardrobe folder in BepInEx/plugins
