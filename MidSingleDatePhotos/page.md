# Mid Relationship Photos

A new mid-relationship cg for every character

## Features

* 12 new photos each featuring a single character

<!-- itch-only -->
## Installation
* Install [**Hp2BaseMod**](https://onesuchkeeper.itch.io/hp2basemod)
* Install [**SingleDate**](https://onesuchkeeper.itch.io/huniepop-2-single-date)
* [**Download**](https://scallycapfan.itch.io/mid-relationship-photos/purchase), unzip and place the `MidRelationshipPhotos` folder in `HuniePop 2 - Single Date/BepInEx/plugins`

(The folder must be `MidRelationshipPhotos`! If it's something like `MidRelationshipPhotos_v1.x.x`, take the `MidRelationshipPhotos` folder out of that one!)
