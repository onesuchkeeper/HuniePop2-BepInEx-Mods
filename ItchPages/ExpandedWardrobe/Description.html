ExpandedWardrobe

Adds new outfits and hairstyles to HuniePop 2 - Double Date.

Features

  • At least 1 new style for every character in the base game!
  • 33 new styles total!

To configure, you may edit the config file BepInEx/config/OSK.BepInEx.ExpandedWardrobe.cfg. This can be done in notepad or any other text editor. There you may turn disable any particular character's styles.

Installation

  • Install Hp2BaseMod
  • Download, unzip and place the ExpandedWardrobe folder in HuniePop 2 - Single Date/BepInEx/plugins

(The folder must be ExpandedWardrobe! If it's something like ExpandedWardrobe_v1.x.x, take the ExpandedWardrobe folder out of that one!)
