AnniversaryTitle

Sloppie Boppie and its 10th anniversary art replaces the title screen of HuniePop 2 - Double Date, fully animated like the Sloppie Boppie Video.

Features

  • Dynamic Animations: Animates with bounces and color tints synchronized across 12 phases of the music track.

  • An absolute Banger: Plays sloppie boppie as the main title menu theme.

Installation

  • Install Hp2BaseMod
  • Download, unzip and place the AnniversaryTitle folder in HuniePop 2 - Single Date/BepInEx/plugins

(The folder must be AnniversaryTitle! If it's something like AnniversaryTitle_v1.x.x, take the AnniversaryTitle folder out of that one!)
