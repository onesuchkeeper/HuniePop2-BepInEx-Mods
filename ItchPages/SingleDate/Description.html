Single Date

Adds HuniePop 1 style single dates to HuniePop 2 - Double Date.

Features

  • Hp1 style single dates with every girl, no fucus switching or stamina!
  • Toggleable baggage on single dates
  • Customizable max relationship level
  • Derpy animated charms

To configure this mod, you must edit the config file BepInEx/config/OSK.BepInEx.SingleDate.cfg. This can be done in notepad or any other text editor.

Important Notes

With the Digital Art Collection DLC installed, charms from the collection will be used. If it's not installed, the charms will use a default image with a "?" on their head. This is not a bug.

The single date cg's are currently all sketches. Art takes me a very long time, if you want to help me afford to pay other people to do it for me consider donating here or via Patreon.

Installation

  • Install Hp2BaseMod
  • Download, unzip and place the SingleDate folder in HuniePop 2 - Single Date/BepInEx/plugins.

(The folder must be SingleDate! If it's something like SingleDate_v1.x.x, take the SingleDate folder out of that one!)
