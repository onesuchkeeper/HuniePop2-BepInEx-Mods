Hp2BaseMod

A modding framework for HuniePop 2 - Double Date.

On it's own this mod doesn't affect gameplay, but it does provide handling and utility for other mods!

It is highly recommended you also install Hp2BaseModTweaks, which provides modded UI support and extra options.  You should always use Hp2BaseModTweaks unless it conflicts with another mod.

Installation

The Hp2BaseMod is built on BepInEx. You must install BepInEx to run it or any dependant mods. See the tutorial for more information.

Once BepInEx is installed, unzip and place the Hp2BaseMod folder in
HuniePop 2 - Double Date\BepInEx\plugins

Other mods based on the Hp2BaseMod must also be placed in
HuniePop 2 - Double Date\BepInEx\plugins

Development

You can view the source code on github

If you discover a bug please check if it has already been reported on github, and if not make an issue for it. Make sure to describe the issue as throughly as you can, list what mods you have installed and what version they are, and include your BepInEx/LogOutput.log file

Documentation for developing mods using the Hp2BaseMod is in progress and will be created as interest demands.
