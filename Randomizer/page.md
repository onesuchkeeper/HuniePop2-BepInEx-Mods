# Hp2 Randomizer

Randomizes the game [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features
* Seeded randomization
* Toggleable name randomization
* Toggleable baggage randomization
* Toggleable pairing randomization
* Toggleable favorite and least favorite affection randomization
* Toggleable inclusion of Kyu and the Nymphojinn
* Toggleable forcing of special characters to swap with normal characters
* Toggleable wings for special character swaps

To configure the randomizer, you must edit the config file `BepInEx/config/OSK.BepInEx.Hp2Randomizer.cfg`. This can be done in notepad or any other text editor.

## Installation
* Install [**Hp2BaseMod**](https://onesuchkeeper.itch.io/hp2basemod)
* [**Download**](https://onesuchkeeper.itch.io/huniepop-2-randomizer/purchase), unzip and place the `Hp2Randomizer` folder in `HuniePop 2 - Single Date/BepInEx/plugins`

(The folder must be `Hp2Randomizer`! If it's something like `Hp2Randomizer_v1.x.x`, take the `Hp2Randomizer` folder out of that one!)
