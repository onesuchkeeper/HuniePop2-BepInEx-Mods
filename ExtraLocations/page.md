# Xtra Locations

Adds new date and sim locations to [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features

* Cut "Hidden Waterfall" sim location
* Bonus songs from the OST
* 7 new date locations
* Fucking fuckin' in a fucking VOLCANO

## Important Notes

With the [Digital Art Collection DLC](https://store.steampowered.com/app/1928520/HuniePop_2_Double_Date_Art_Collection/?curator_clanid=39584304) installed, the cut Hidden Waterfall sim location will be added

With the [HuniePop 2 - Double Date OST DLC](https://store.steampowered.com/app/1556630/HuniePop_2_Double_Date_OST/?curator_clanid=39584304) installed, bonus tracks from the OST will be used at a few locations.

By default, the mod assumes these are in the default install locations used by steam. If you have them installed elsewhere you must edit the `DoubleDateOstDir` and `DigitalArtCollectionDir` values in `BepInEx/config/OSK.BepInEx.ExtraLocations.cfg`. You can do this in notepad or any other text editor.

<!-- itch-only -->
### Installation
* Install [**Hp2BaseMod**](https://onesuchkeeper.itch.io/hp2basemod)
* [**Download**](https://onesuchkeeper.itch.io/huniepop-2-xtra-locations/purchase), unzip and place the `ExtraLocations` folder in `HuniePop 2 - Single Date/BepInEx/plugins`. 

(The folder must be `ExtraLocations`! If it's something like `ExtraLocations_v1.x.x`, take the `ExtraLocations` folder out of that one!)
