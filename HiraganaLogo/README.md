# HiraganaLogo

Adds a new logo featuring Hiragana to [HuniePop 2 - Double Date](https://huniepop2doubledate.com/).

## Features

* A new logo for the title screen

## Dependencies & Installation

### Requirements
* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](../Hp2BaseMod/README.md)

### Installation
* Install [**Hp2BaseMod**](../Hp2BaseMod/README.md)
* [Download](https://onesuchkeeper.itch.io/huniepop-2-hiragana-logo), unzip and place the HiraganaLogo folder in BepInEx/plugins
