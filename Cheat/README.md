# Cheat

Dev tool for temporary test code and gameplay cheats to use while developing mods.

## Features

* Configurable Cheats for:
  * Unlock all styles on startup
  * Meet all girls on startup
  * Learn all favorites on startup
  * Learn all baggage on startup
  * Set fruit counts on startup
  * Add affection to every match
  * Add moves to every match
  * Add stamina to every match
  * Add sentiment to every match
  * Add passion to every match
  * Add affection to bonus round matches
  * Refill stamina while talking at sim locations

## Important Notes

Cheat is not an officially released or supported mod. It will be changed as needed for development without notice.

## Dependencies & Installation

### Dependencies
* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](../Hp2BaseMod/README.md)

### Installation
* Install [**Hp2BaseMod**](../Hp2BaseMod/README.md)
* Build and place OSK.BepInEx.Cheat.dll in `HuniePop 2 - Double Date/BepInEx/plugins/Cheat`
