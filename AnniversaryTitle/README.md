# AnniversaryTitle

Sloppie Boppie and its 10th anniversary art replaces the title screen of [HuniePop 2 - Double Date](https://huniepop2doubledate.com/), fully animated like the [Sloppie Boppie Video](https://www.youtube.com/watch?v=Fr7AgTsS--w).

## Features

* **Dynamic Animations**: Animates with bounces and color tints synchronized across 12 phases of the music track.

* **An absolute Banger**: Plays [sloppie boppie](https://www.youtube.com/watch?v=Fr7AgTsS--w) as the main title menu theme.

## Dependencies

* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](https://onesuchkeeper.itch.io/hp2basemod)
