# AnniversaryTitle

Sloppie Boppie and its 10th anniversary art replaces the title screen of [HuniePop 2 - Double Date](https://huniepop2doubledate.com/), fully animated like the [Sloppie Boppie Video](https://www.youtube.com/watch?v=Fr7AgTsS--w).

## Features

* **Dynamic Animations**: Animates character and background layers with custom bounce curves and color tints synchronized across 12 phases of the main music track (e.g., Dawnwood Park, Farmer's Market, Lustie's Nightclub, Bedroom, Reprise).

* **An Absoulte Banger**: Loads and plays `Sloppie Boppie.wav` as the main title menu theme.

## Dependencies & Installation

### Dependencies
* [**HuniePop 2 - Double Date**](https://huniepop2doubledate.com/)
* [**BepInEx**](https://github.com/BepInEx/BepInEx/releases)
* [**Hp2BaseMod**](../Hp2BaseMod/README.md)
* [**Hp2BaseModTweaks**](../Hp2BaseModTweaks/README.md) (Optional)

### Installation
* Install [**Hp2BaseMod**](../Hp2BaseMod/README.md)
* [**Download**](https://onesuchkeeper.itch.io/huniepop-2-anniversary-title), unzip and place the AnniversaryTitle folder in BepInEx/plugins
